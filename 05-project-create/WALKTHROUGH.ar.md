# تعريف مشروع — الإنشاء والتجهيز

1. داخل مساحة جامعة بغداد، نختار تعريف مشروع جديد. نبدأ بمشروع إنشاء مبنى المختبرات التعليمية في مجمّع الجادرية. الاسم يصف العمل المطلوب، بينما يحدّد النوع المسار الذي سيستخدمه المشروع.

2. نُكمل جهة المشروع وموقعه وتصنيفاته. اختيار النوع الإنشائي يجعل المتابعة مرتبطةً بأعمال التنفيذ والكميات والأنشطة. نختار القيم من القوائم، حتى تبقى بيانات المشروع قابلةً للتصفية والتجميع.

3. نحدّد مصدر التمويل وحالة المشروع، ونُدخل الكلفة المقرّرة. هذه كلفة المشروع، وليست دفعةً مصروفة. وسنُعرّف تفاصيل العقد ومكوّناته المالية في الخطوة التالية.

4. نُراجع العنوان والبيانات المدخلة قبل الحفظ. بعد إنشاء المشروع، تظهر صفحة معلوماته ورقمه المرجعي، وتصبح وحدات العقود والجدول الزمني والإنجاز متاحةً من القائمة الجانبية.

5. ننتقل إلى المثال الثاني: تجهيز مختبرات البحث العلمي في مجمّع الجادرية. نختار نوع التجهيز، لأننا سنتابع أصنافاً وأجهزةً وتوزيعاً على الجهات المستفيدة، ثم فحصاً واستلاماً.

6. نُكمل معلومات مشروع التجهيز وتمويله وكلفته، ثم نحفظه. سيُنشأ عقد هذا المشروع بالدولار الأمريكي، بينما يكون عقد الإنشاء بالدينار العراقي. يجب دائماً قراءة العملة إلى جانب المبلغ، وعدم جمع قيمٍ بعملتين مختلفتين مباشرةً.
