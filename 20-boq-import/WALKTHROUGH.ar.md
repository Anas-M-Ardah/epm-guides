# استيراد جدول الكميات من Excel

الفيديو يبدأ من جدول PRJ-0001 بعد تطبيق الأمر VO-01. ملف training-boq.xlsx المرفق تدريب اصطناعي مطابق للقيم النافذة: BQ-001 بكمية 110 م³ وسعر 4,000؛ BQ-002 بكمية 200 م² وسعر 2,000. إجمالي البنود 840,000 د.ع. لا توجد بيانات حقيقية في الملف.

## خطوات المعالج

1. افتح جدول الكميات واضغط استيراد. اختر ملفExcel. يقبل المعالج أيضاًCSV/TSV؛ لم نجربهما في هذا الفيديو.
2. طابق code مع الرمز، description مع الوصف، division مع المجموعة، unit مع الوحدة، qty مع الكمية، rate مع سعر الوحدة. الحقول ذات النجمة إلزامية والمجموعة اختيارية. راجع المعاينة ولا تفترض صحة المطابقة التلقائية.
3. اضغط التالي للتحقق. يبدأ ترقيم البيانات بالصف 2 لأن الصف 1 للعناوين. ظهر «لا ملاحظات» ومجموع الأوزان 100%.
4. راجع المقارنة: مضاف 0 ومحذوف 0 ومعدل 0 ودون تغيير 2. القائمة 840,000 والمستوردة 840,000 والفرقصفر. المقارنة تخص البنود، وليست قيمة العقد 990,000.
5. اختر نوع الجدول: إصدار أول أو تحديث حالي أو مراجعة تعاقدية. اخترنا مراجعة تعاقدية ثم تقديم للاعتماد.

## الصلاحيات وحماية الجدول

بدأ التسجيل بصفة مهندس مقيم. ظهر زر الاستيراد لكن الخادم منع المتابعة برسالة أن الاستيراد من صلاحيات المستخدم المختص في الجهة. أغلقنا المعالج وبدلنا إلى مختص جامعة بغداد ثم أعدنا الملف نفسه. اكتمل التقديم وأصبح الإصدار 1 من صفين بقيمة 840,000، بتاريخ بيانات 2026-09-30. التقديم يحفظ نسخة ولا يستبدل الجدول النافذ.

بدلنا إلى مدير مشروع فظهر «اعتماد الإصدار». عند الضغط رفض النظام: «بنود مُعاد تسعيرها بأمر تغييري مطبَّق (BQ-001) لا تُستبدل من ملف». هذا منع فعلي حتى مع تطابق الأرقام. انتهى الفيديو بالإصدار مقدماً دون اعتماد، وبقيت البنود النافذة على حالها. لا يمثل هذا نجاح اعتماد أو استبدال. لا تعالج هذه الحماية بتغيير الكود أو حذف الرابط؛ راجع الأثر التعاقدي في مساره الصحيح.

## قراءة النتيجة

شريط النسخة يبين رقمها وعدد الصفوف والقيمة والمقدم والتاريخ. سجل البنود أسفله هو النافذ. ظهور «قدمت النسخة» لا يعني اعتمادها. في هذا المثال ظل إجمالي 840,000 ووزن الخرسانة 52.38% وكمية 110. هذا السيناريو يشرح التقديم والمراجعة والحماية، ولا يدعي عرض اعتماد ناجح لبند مرتبط بملحق.
